# 🛠️ Industrial Predictive Maintenance System

A Machine Learning pipeline designed to predict mechanical equipment failure using multi-sensor telemetry data (Temperature, Vibration, Torque, Tool Wear).

## 📌 Project Overview
- **Goal:** Predict machine downtime before failure occurs to optimize maintenance schedules.
- **Tech Stack:** Python, Pandas, NumPy, Scikit-Learn, XGBoost, Matplotlib, Seaborn.
- **Domain:** Mechanical Engineering & Industrial Data Analytics.
